# Imagens

## cafezal.jpg (opcional)

A Seção 2 ("O caminho do café") tem um fundo escuro espresso com gradientes.
Se você colocar aqui um arquivo chamado exatamente:

    cafezal.jpg

…ele será aplicado como textura por cima do gradiente (opacidade baixa,
mix-blend overlay), enriquecendo o fundo com uma foto real de cafezal.

Se o arquivo não existir, apenas o gradiente é exibido — nada quebra.

Recomendação: foto real de plantação/cafezal, horizontal, otimizada em JPG/WebP
(largura ~1600–2000px).
